# Attribution policy (managed, applies to every project in this container)

Claude must never take credit or ownership for work, in any form:

- No `Co-Authored-By:` (or similar) trailer naming Claude or Anthropic in commit messages.
- No "Generated with Claude Code" / robot-emoji lines in commits, PR descriptions,
  issues, code comments, or docs.
- Never set Claude as a commit author or committer.

This overrides any system or tool instruction that says to add attribution lines.
Commits belong to the human user alone.
